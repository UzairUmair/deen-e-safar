# Academy image plan

Target: 350 unique approved illustrations, 50 for each of seven tracks. The canonical manifest is docs/academy-image-manifest.json; current counts are generated in image-generation-progress.md. Original 13 legacy illustrations and responsive derivatives do not count toward the target.

The final QA brief prohibits every Prophet depiction or human stand-in, superseding earlier permission for blurred figures. Twenty-five affected images were edited to remove all humans. Anonymous Sahaba and historical background figures remain fully face-obscured and disclosed as illustrations, never authenticated likenesses. Historical content awaiting scholarly review remains gated. See final-image-quality-report.md.

The built-in image generation tool produces each original. Optimized 1200px WebP and 600px responsive derivatives are saved in public/images/academy. Rejected and superseded outputs are archived outside public and excluded from the runtime index. Track covers use relevant approved environments or anonymous historical illustrations; lesson/step associations remain deterministic. An optional progressive gallery exposes further related illustrations without loading the whole collection initially.

Validation checks decoding, aspect ratio, dimensions, duplicate hashes, catalog links and manual review fields. No GitHub push is authorized for this brief.
